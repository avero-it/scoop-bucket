# avero-it Scoop bucket

Scoop manifests for [sie](https://github.com/avero-it/sie), the siMPLE eDITOR: a modeless terminal text editor.

```powershell
scoop bucket add avero-it https://github.com/avero-it/scoop-bucket
scoop install sie
```

The manifest is updated automatically by each sie release; don't edit it by hand.
